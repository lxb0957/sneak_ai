# 让每一局都留下点东西

这一版没有新关卡、没有新敌人、没动平衡。加的是**两件"这一局发生过什么"的事**：练过的那十遍有痕迹，输掉的那一局能查账。

## 一、跳关练习终于有反馈

原来的规则写在 `_handle_scoring` 里，一行：

```python
if self._start_level > 0:
    return          # 从第 N 关起步的局，不提交成绩
```

理由站得住：从第 3 关起步只要 35 秒就能"打完三关"，交上去就是一条永远刷不掉的假纪录。

但代价从来没人算过。第 4 关机器人胜率 **25%（95% 区间 17~35%）**，是五关里唯一的断崖；卡在那儿的人跳关练十遍，每遍都在进步，屏幕上一句话都没有。**练习没有反馈，就没有理由再点一次开始。**

现在拆成两套纪录：

| | 认什么 | 出现在哪 |
|---|---|---|
| 整局纪录 | 从第 1 关起步、一路打到底（**口径一点没动**） | 菜单「最佳纪录」、结算页 |
| 单关纪录 | 从第 N 关起步，**且打的就是第 N 关** | 菜单选关行「本关最佳 812 分」、结算页 |

那半句"且打的就是第 N 关"是关键。`_carry` 会把前面的用时灌进新世界，从第 1 关连打到第 3 关时，第 3 关的 `elapsed` 里含着一二关的时间。拿去和"直接挑战第 3 关"比，练习分永远低于正式分——**一个永远追不上的分数，比没有分数更打击人**。起步关没有 carry，`world.record()` 天然干净，一行判断就够。

顺手修掉一处老 bug：跳关局的结算页原来摆着跨五关的整局纪录。那是一辈子在这一局里都够不着的数字，所以「新纪录」三个字**从来没亮过**。现在按起步关选纪录。

## 二、局后按 Tab，看这一局怎么崩的

结算页只有四个数：用时、被发现、击倒、得分。它回答不了一个真正的问题——**我是从哪一关开始崩的？崩之前是谁先看见我？**

数据其实一直都在：`_carry` 记着每关带过来的计数，`ai/trace.py` 记着整局决策流。问题是 trace 的两个出口（F1 面板、`--trace` 导出的 JSONL）**都是给开发者的**，玩家一个都够不着。现在多了第三个：结算页按 **Tab**。

```
逐关                              关键时刻
哨站       66.9 秒  没被发现过        48.4s  被看见 → 转入追击
环形枢纽   53.7 秒  被发现 2 · 石子 3  48.4s  目击者喊了一声，附近的人都过来了
回廊       87.4 秒  被发现 4 · 石子 2  66.9s  抵达撤离点
```

一关无声无息地过去，写的是「没被发现过，也没动手」，不是「被发现 0 · 击倒 0 · 石子 0 · 开枪 0」——后者看着像一张没填完的表，而前者是一句结论。

为此补了两个计数（`stones_thrown` / `shots_fired`）并纳入跨关携带。原来只有 `decoy_hits`（"真的引开了几个人"），于是往空地扔三颗石子的人，在读到的数据里像什么也没做。

## 两处静默坑，都是"跑得通但内容说错"

**累计 vs 增量。** 第 3 关的 `elapsed` 含着一二关的时间（`_carry` 故意灌的，否则结算页的"累计用时"会变成"只算最后一关"）。直接显示会得到 66 → 120 → 174 秒的单调递增假表格，玩家只会觉得"我越打越慢"。改成一次减法。

**同一帧的因果。** trace 的时间戳按帧推进，"喊人"（广播在敌人更新之前）和"被看见"（追击判定在后）时间戳完全相同。照原序读就是"他们先喊了一声，然后才看见我"——因果讲反了。用一张优先级表排一次，而且排序放在 `key_events()` 里、不放在调用方，否则逐关和整局两个出口迟早有一个忘了调。

## 验收

- **28 个测试脚本全绿**，新增 `test_w29`（单关纪录，6 组）与 `test_w30`（复盘页，7 组）
- **五处错误方向都摘掉修复验过会红**：破整局纪录时冲掉单关榜 / 把"只认起步关"改成"每关都记" / 复盘页改成累计口径 / 摘掉同帧排序 / 把行距改成 −24 制造叠字
- **端到端真跑**：机器人从菜单选第 4 关，54.4 秒 / 863 分 / A 评级通关，存档里只有 `per_level["3"]`、没有整局字段
- `audit_ui` 三分辨率零重叠；复盘页在 800×600 / 1024×768 / 1280×960 / 1920×1080 四种窗口都能画出、且块与块不重叠
- 老存档照旧能读：没有 `per_level` 字段的 `records.json` 读成空表，不报错、不覆盖

## 怎么玩

双击 `StealthProtocol-v1.8.8-win64.exe`，不用装 Python。

- 想看 AI 在想什么：**F1**
- 想复盘刚打完的一局：结算页按 **Tab**（再按一次回来）
- 想练某一关：主菜单用 **← →** 选关，单关成绩会记在选关行上，但**不进整局总榜**
- 想先确认它能在这台机器上跑：`StealthProtocol-v1.8.8-win64.exe --selfcheck`（跳过菜单，五关各跑 120 帧，退出码就是结论）
