# 可直接粘贴的发帖文案

每个 `.txt` 只有两块，`===== TITLE =====` 下面一行是标题，`===== BODY =====` 下面是正文。
方块标记行本身不要复制进去。

| 文件 | 平台 | 什么时候发 |
|---|---|---|
| `01-r-pygame.txt` | r/pygame | 先发这个，最对口 |
| `02-v2ex.txt` | V2EX 分享创造 | 隔一天 |
| `03-show-hn.txt` | Hacker News (Show HN) | 等前面收到反馈后 |

完整版（含每个平台为什么这么写、注意什么、小红书 / B 站 / X 的稿子）在
[`../itch/promo-copy.md`](../itch/promo-copy.md)，数字只从那里的事实卡抄。

## 发之前

- **Reddit 用 text post 发**，正文里的链接会正常显示。想改成 link post（带缩略图卡片）
  就把正文最后那两行链接删掉，URL 填进 Link 框。
- **新号别连发**。Reddit 对账号年龄和 karma 有隐性门槛，刚注册的号发两三个子版会被静默过滤
  —— 不报错，就是没人看见。先攒点正常回帖。
- **一次只发一个平台**，发完守着评论区两小时。同一天铺五个地方的结果是五处都没人理。
- 配图：**优先发视频**。`assets/demo.mp4`（67 秒 / 960×720 / 5.3 MB，完整一局 66.3 秒通关）
  给 r/pygame；`assets/x-clip.mp4`（16 秒 / 1.7 MB，"被发现 → 甩脱"那段）给 X 或短帖。
  GIF（432 宽）是 GitHub README 专用的妥协——GitHub 的 markdown 不放 mp4，别把它贴去 Reddit。

## 不要说的

- 不说"零依赖"（有 pygame，打包进 exe 了）。
- 不说"AI 会学习"（没有机器学习，说错一次会被追着问）。
- 不说第 4 关"故意设计得难"（它是没解决，`docs/KNOWN_ISSUES.md#A1` 里认了）。
